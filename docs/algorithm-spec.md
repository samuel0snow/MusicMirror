# 算法与解释规范

设计依据：[完成指南](design/项目完成指南.md) 第6–13、24节。版本 `music-profile-mvp-1`；权重与阈值集中在 `packages/algorithms/src/config.ts`。

真实双输入字段覆盖、导出方法与下一阶段算法决策见[双输入实测与画像决策](data-export-and-profile.md)。首轮曲风/语言无覆盖，后续已通过[百科补全](metadata-enrichment.md)取得平台标签及语种；它们可进入相应分布统计，仍不能用现有指数推出旋律、人声、情绪或人格。本版保留为未校准的结构统计。

## 标准化与数学层

同songId聚合有效计数，负/null/非数值忽略并warning，大有限计数保留且标记。长期合并后取正播放Top100。最近列表按events/unique来源处理，真实适配器默认unique，不把去重列表当完整事件频次。

缺少元数据仍计算歌曲层；艺人/专辑按已知维度归一化并附覆盖率。合作艺人均分播放，作品数各计一首。收藏模块每首先权重1，再均分艺人。

概率p=x/sum(x)；TopKShare=前K概率和；HHI=sum(p²)；ESS=1/HHI；HHI_norm=(HHI-1/N)/(1-1/N)；Entropy=-sum(p ln p)。单项归一化熵为0，HHI_norm为1。空输入特征有限，但相关指数null。

Jaccard=交集/并集，Retention=交集/长期集合。JSD对齐ID并使用log2，零项按极限0处理，缺失分布不能进入打分。

## 六大指数

| 指数 | raw | 最低数据 |
| --- | --- | --- |
| concentration | .45 HHI_norm + .35 C10 + .20(1-ESS/N) | 10首长期歌曲 |
| deepListening | .65艺人深度+.35专辑深度；d=min(1,ln(1+n)/ln(1+cap))，cap=10/8 | 10首、3艺人 |
| breadth | .70艺人归一化熵+.30专辑归一化熵 | 15首、可靠元数据 |
| exploration | .60近期新歌+.25新艺人+.15新专辑比例 | 长期有效、近期≥20 |
| stability | .55 Top20留存+.45(1-艺人JSD) | 长期与近期均有效 |
| intentAlignment | .30红心歌曲比例+.70红心播放加权比例 | 喜欢列表成功、长期有效 |

元数据维度完全缺失时重分配剩余权重并降置信度。核心输入不足时value/raw=null、confidence=0、reason解释。所有指数返回factors和algorithmVersion。

MVP value=round(clamp(raw,0,1)*100)，是未校准描述值，不是人群百分位。未来校准升级版本，不覆盖快照。置信度由样本量、元数据覆盖、新鲜度、去重来源折扣组成；长期min(N/100,1)，近期min(条数/100,1)，时间未知乘.5，unique乘.7，已知时间衰减exp(-ageDays/7)。

## 双模块与变化

长期模块按播放，收藏模块按歌曲等权，保留歌曲、likedAt、红心验证、来源与交集/新艺人/JSD。未知时间不推断近期；没配置返回空态。曲风/语言/年代仅在元数据可靠时展示并附覆盖，不推断旋律/情绪。

核心歌曲满足Top20、份额≥2%、次数≥中位数2.5倍任一，并记录原因；核心歌手份额≥5%或作品≥4且份额≥3%。

对比输出核心进出、艺人份额与同版本指数差值。指数变化≥8、份额变化≥5个百分点才生成变化洞察，低置信度抑制强结论。至少3个同版本可比快照才描述趋势。洞察保留evidence/templateKey/params。
