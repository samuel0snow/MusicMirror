新增记录应列明：查询日期、来源/部署版本、授权与样本范围、请求结果、客户端确认、未确认项、本机证据目录。私有响应不写入本目录；保存规则见[隐私说明](../privacy.md)与[数据目录](../test-data-layout.md)。
